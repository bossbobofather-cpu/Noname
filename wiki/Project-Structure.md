# 프로젝트 구조

저장소는 Unity 프로젝트와 로컬 UPM 패키지를 함께 포함합니다.

```
Noname/                        # 저장소 루트
  Noname/                      # Unity 프로젝트 루트
    Assets/
    Packages/
    ProjectSettings/
  UpmPackages/
    com.noname.gameabilitysystem.plugin/
```

- `Noname/` 아래가 Unity 프로젝트 루트입니다.
- `UpmPackages/`는 로컬 UPM 패키지를 보관하는 폴더입니다.
